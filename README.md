💻 Desafio CSS — TechNews Today 🚀

Este repositório contém a resolução do desafio prático da Aula 10, onde o objetivo foi criar o portal de tecnologia TechNews Today utilizando apenas CSS puro, aplicando conceitos modernos de design e mantendo a estrutura HTML intacta.

📋 Sobre o Projeto

O TechNews Today é um portal responsivo com notícias de tecnologia, seção de vídeo em destaque e formulário para assinatura de newsletter.

O projeto tem como foco entregar uma interface moderna utilizando técnicas de CSS, sem dependência de frameworks ou JavaScript.

📑 Checklist do Desafio

Todos os requisitos exigidos na atividade foram implementados com sucesso:

 Glassmorphism: Cabeçalho com efeito de vidro fosco (backdrop-filter).

 Gradiente no Texto: Título da logo estilizado com gradiente de cores.

 CSS Grid: Disposição dos elementos de vídeo e newsletter lado a lado.

 Header Fixado: Navegação no topo com position: sticky.

 Responsividade: Regras de media query adaptadas para dispositivos móveis.

 Código Enxuto: Arquivo CSS otimizado contendo no máximo 50 linhas.

 Sem Dependências: Projeto 100% puro, sem frameworks, JavaScript ou alterações no HTML.
